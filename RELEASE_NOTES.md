# SideQuests v0.2.0

Erste Android-Testveröffentlichung von SideQuests 0.2.0.

- Quest-Journal mit Haupt- und Nebenquests
- Ziele/Teilaufgaben und Chronik-Einträge
- Kategorien, Suche, Fälligkeit und wiederkehrende Quests
- JSON-Backup exportieren und importieren
- Dunkles Leder-/Pergamentthema mit optionalem hellem Thema

**Hinweis:** Das Veröffentlichungs-Skript baut standardmäßig eine installierbare Debug-APK, die mit dem Android-Debug-Schlüssel signiert ist. Das eignet sich für Tests. Für eine dauerhafte öffentliche Produktionsveröffentlichung sollte anschließend ein eigener Release-Schlüssel eingerichtet und sicher aufbewahrt werden.
